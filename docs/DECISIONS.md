### Contract changes

- **D5. `oversample` removed** from `build_operator`. The fine (simulation) operator is
  `build_operator(2n, thetas, n_det=2*(n+2))`.
- **D6. Guard bins.** Coarse `n_det = n + 2`; fine `n_det = 2*(n+2)`, so pair-binning gives
  `n + 2`. Operator tests use images supported inside the mask.
  - Interpretation (needs owner confirmation, see O2): `build_operator(n, thetas_deg, n_det=None)`
    treats `None` as `n + 2`.
- **D7. Phantom.**
  - `make_fine_phantom(n, lesion=False) -> [2n, 2n]`; `block_mean(fine) -> [n, n]`;
    `make_phantom(n, lesion) = (block_mean(fine), mask)`.
  - `skimage.transform.resize(..., anti_aliasing=True)` is approved, from the 400x400
    `skimage.data.shepp_logan_phantom()` to `2n x 2n`.
  - The lesion is a small disk on the fine grid inside a UNIFORM region of the phantom.
    A test checks that uniformity.
- **D8. `simulate_scan(fine_truth, thetas_deg, counts, seed)`** takes the FINE truth `[2n, 2n]`.

### Metrics

- **D9. PSNR** is hand-written: MSE over MASK pixels only, `data_range = 1.0`; identical images
  give `inf`.
- **D10. SSIM** is `skimage.metrics.structural_similarity` with `full=True`, `win_size=7`,
  `data_range=1.0`, `gaussian_weights=False`. The reported value is the mean of the returned SSIM
  map over mask pixels. (Signature to be verified with `help()` in Step 1, per SPEC rule 1.)
- **D11. Lesion metrics.** `lesion_contrast = (mu_L - mu_B) / mu_B`;
  `background_noise = sigma_B / mu_B`; `contrast_recovery = contrast_rec / contrast_truth`.
  `score(...)` therefore also returns `contrast_recovery`.
- **D12. ROIs.** Lesion ROI = the lesion disk eroded by 1 px. Background ROI = a same-size disk in
  another uniform region, not overlapping the lesion.

### Tests and methods

- **D13. MLEM conservation test** uses data generated by the SAME coarse operator,
  `m = Poisson(A x)`. The real deviation is measured first, then the tolerance is set
  (replaces the fixed "1e-6 relative" in Step 5).
- **D14. FBP scale** is derived for the exact discretisation used, verified with the noise-free
  test, and never fitted to the truth.
- **D15. Non-oracle stopping.** The iteration count is chosen per (angles, counts) on tuning seeds,
  then applied unchanged to reporting seeds. Oracle results stay labelled separately.
- **D16. TV** is applied to `x / scale`. `beta` is tuned per (angles, counts) on tuning seeds from a
  small log-spaced grid chosen after measuring. OSL instability is noted in the README.

### Experiments

- **D17. Seeds.** Tuning: 100-104. Reporting: 0-9.
- **D18. Limited-angle.** 3-degree spacing; ranges 90, 120, 150, 180 degrees
  (30, 40, 50, 60 angles).
- **D19. Timing gate.** Before Step 9, time one run at `n=64` and at `n=128` and estimate the
  full grid. If it exceeds ~2 hours, propose a reduction and wait for owner approval.

## Open questions

- **O1. `mlem_tv` signature vs D16.** TV on `x / scale` needs `scale`, but the frozen contract
  `mlem_tv(op, m, n_iter, beta, mask, callback=None)` has no `scale` argument. Options:
  (a) add a `scale` argument (contract change), or (b) the caller passes a `beta` already
  expressed for `x / scale`. Not changed; owner decision needed before Step 7.
- **O2. `build_operator` default.** D6 does not say what `n_det=None` means. The SPEC table now
  reads `None` as `n + 2`. Owner confirmation needed before Step 2.
- **O3. Limited-angle overlap.** Limited-angle range 180 degrees at 3-degree spacing (60 angles) is the
  same geometry as the full-range 60-angle setting; both will be run as listed unless the owner
  says otherwise.
